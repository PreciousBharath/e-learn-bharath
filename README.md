## 📚 About the Project

**E-Learn** is a lightweight, single-page **e-learning website** built with pure **HTML, CSS and JavaScript** — showcasing courses, instructors and a call-to-action in a modern, responsive layout. No build tools needed: just open and learn.

## ✨ Key Features

- 🏠 Hero section with course call-to-action
- 📚 Course cards and categories
- 👨‍🏫 Instructor / about section
- 📱 Responsive design for mobile & desktop

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | HTML5 · CSS3 · JavaScript |
| Hosting | GitHub Pages / Netlify ready |

## 📂 Project Structure

```text
e-learn-bharath/

```

## 🚀 Getting Started

```bash
git clone https://github.com/PreciousBharath/e-learn-bharath.git
```
